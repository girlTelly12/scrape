ระบบดึงข้อมูลหลายเว็บไซต์

กรอกเว็บไซต์หลักเพื่อให้ระบบตรวจผู้พัฒนาและเลือก Adapter เท่านั้น ลิงก์จัดซื้อจัดจ้าง ข่าวประชาสัมพันธ์ กิจกรรม และหมวดเพิ่มเติม ให้ผู้ใช้กรอกเอง ระบบจะไม่เติมหรือเขียนทับ

ตรวจสอบระบบก่อนเริ่มงาน

ระบบไม่เติม URL หมวดอัตโนมัติ ผู้ใช้เป็นผู้กำหนด URL ทุกช่อง
ยังไม่ได้ตรวจผู้พัฒนาเว็บไซต์

สำรวจหน้าสาธารณะในโดเมนเดียวกัน เก็บ HTML, ข้อความ, PDF, Office, ZIP, รูปภาพ, วิดีโอ, เสียง, CSS, JavaScript และ Font พร้อม Resume/Checkpoint หากมีหน้าตรวจสอบ Cloudflare ให้ดำเนินการเองใน Chrome ที่เปิดผ่านพอร์ต 9222

กด ค้นหาหมวดจากเว็บ เพื่อดึงหมวดทั้งหมดจากเมนูเว็บไซต์อัตโนมัติ (ใช้ลิงก์จากช่อง “เว็บไซต์หลัก”) แล้วติ๊กเลือกเฉพาะที่ต้องการ
